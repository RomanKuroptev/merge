# Writing Code While It Runs

Live coding means you write a program while it is already running, and the sound or picture changes as you type. No build step, no waiting. You edit the thing and the thing reacts, like tuning a radio that is also the song. Musicians do it on stage, projecting their screen so the crowd can watch them think. I like the idea of being watched while I make a mess. Mine would be a lamp that flickers every time I hesitate, which is most of the time.
