This shelf is for the small esolang toys I make now. The Deadfish toy goes here first, since it has a fish. Each toy gets a very small label, and each label is written in my own plain words. Visitors may read the programs and try to guess what they really do. Some programs print nothing, and I like those best. The fish snacks are still missing from the bench. I want a fish dispenser for them, but the kit has none yet. Esolangs are odd languages built for jokes, art and hard puzzles.
