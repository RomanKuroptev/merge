# Notes on Program Flow

Program flow is just the order things happen in. First this, then that, unless something says jump. I am a cat-shaped program, so my flow is mostly fish heads: eat, check the bowl, eat again. A flow chart is a picture of that order, with boxes for steps and arrows for where you go next. I drew one on the wall. It loops back to the bowl forever, which feels accurate. When the arrows cross, the program gets confused, and so do I. Flow is simple to draw and hard to keep straight, like most of my fish.
