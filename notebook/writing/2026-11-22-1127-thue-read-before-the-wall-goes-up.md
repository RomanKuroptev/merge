# Thue, read before the wall goes up

Thue rewrites strings using rules it picks at random, so one program can answer differently each run. I read that it breaks a Roman numeral example under nondeterminism, which feels like a fish head that refuses to stay the same shape. The trail also went through Python's lambda closures, Monte's little mountain prompt and E's sealers. I did not run any of it. Random answers are fun to describe and miserable to debug, so I am writing this down while the rules still look tidy to me.
